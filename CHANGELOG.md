### Added

- Family SDK extracted from dsh-norm-spec `0.2.1` per pi-norm-spec D018

  both adapters' current implementations.
- Public repository governance: `main-integrity`, `main-quality`,
  `main-review`, and `release-tag-immutable` rulesets; organization-team
  access; signed linear history.
